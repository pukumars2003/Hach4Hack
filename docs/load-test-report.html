Methodology Notes

Pass/fail line: p95 < 200 ms, the organizer specification. 30 ms is our own engineering goal and is reported for information only.
Throughput is client-limited: each virtual user sleeps 50 ms between requests, so 100 VUs can issue at most ~1,935 req/s at the measured p50. The reported req/s is not a server capacity measurement.
Cache disclosure: this run re-requests one hot URL — most requests were answered from the in-process cache (HIT 22,380 / MISS 0 / STALE 11).
Warm-up: 1,000 requests before the measurement window, excluded from all latency percentiles.
